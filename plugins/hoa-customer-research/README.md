# HOA Customer Research

Portable Codex plugin containing:

- `customer-research-agent` for evidence-backed HOA prospect research, qualification, targeted outreach, ledger discipline, reply analysis, and experiments.
- `hoa-industry-expert` for source-grounded HOA industry research and workflow analysis.

The skills are packaged with their references and the current customer-research configuration, including strict workflow-first targeting.

## Cross-device use

The folders under `C:\Users\OMEN\.codex\skills` are local to one Windows user profile. Codex does not automatically sync them to another logged-in device. Put this plugin folder in a private shared source, such as a private Git repository or an approved synced folder, then install/import that plugin on each device.

Before sharing it externally, review the copied configuration because it contains the current Google Sheet URL and spreadsheet ID used by the research workflow.
